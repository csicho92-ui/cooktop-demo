# RBR-GF3100C 조작 체험

가스쿡탑 레인지 RBR-GF3100C(BOGF610C)의 터치 조작부를 사용설명서대로 눌러 볼 수 있는 웹 체험 페이지입니다.

**바로 열기:** https://csicho92-ui.github.io/cooktop-demo/

## 할 수 있는 것
- 3D 쿡탑을 드래그해 돌려 보고, 상판 위 조작부를 직접 누르기
- 전원·잠금·점화·화력(1~9단)·타이머(0~99분)·후드 연동
- 세이프티 락, 음성 안내·멜로디·음량·멜로디 테마 설정 (동시 누르기)
- 냄비 과열 시 자동 불꽃조절(A 표시), 에러 코드 발생과 해제
- 스마트링크 앱 블루투스 페어링 흐름 (PIN 017802)
- 앱에서 레시피 전송 → 르플레 전용 냄비 → 켜짐 키로 자동조리 (단계별 화력 자동 조절, 남은 시간, 완료 알림)
- 우리집 레시피 등록 (화력별 최대 40분, 총 2시간, 9단 합계 59분 제한 반영)
- 9단 1시간 자동 소화, 3분 자동 전원 꺼짐을 60배속으로 확인

## 참고
- 파일 하나(`index.html`)로 동작합니다. 3D 화면은 cdnjs의 three.js r128을 불러옵니다.
- 자동조리 레시피의 화력과 시간은 체험용 예시 값입니다.
- 사용설명서와 제품 소개 자료를 바탕으로 만든 비공식 시뮬레이터라서 실제 제품과 반응이나 표시가 다를 수 있습니다. 설치와 안전 관련 내용은 제품 사용설명서와 서비스 센터(1544-3651)를 기준으로 확인하세요.
